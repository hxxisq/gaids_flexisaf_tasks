# Tic-Tac-Toe AI

# Week 2 Internship Tasks

This repository contains the completed exercises for Week 2, which include an AI game simulation and data visualization scripts.

## 1. Tic-Tac-Toe AI
A Python implementation of a terminal-based Tic-Tac-Toe game featuring an unbeatable AI opponent.
* **Algorithm:** Uses the Minimax algorithm to evaluate all possible future moves and play optimally.
* **Features:** Playable directly in the console with input validation and automatic win/tie detection.
* **Usage:** Run the Python script and enter a number (0-8) to place your `X` on the board.

## 2. Company Sales Data Visualization
A data analysis project using `pandas` and `matplotlib` to visualize product sales data from `company_sales_data.csv`.
* **Exercise 1:** A custom line plot displaying the total profit across all 12 months.
* **Exercise 2:** A 2x1 vertical subplot comparing the monthly sales units of Bathing Soap and Facewash.
* **Usage:** Ensure `company_sales_data.csv` is in the same directory as the script or Jupyter Notebook before running the cells to generate the plots.

Student Performance & Attendance Analysis¶

Problem statement: Schools collect attendance, homework, and exam data separately, making it hard to see how these factors relate to each other at a glance. This notebook cleans, merges, and analyzes those datasets to surface subject-level performance trends, attendance patterns, and the relationship (if any) between attendance/homework habits and exam scores.

Dataset: Student Performance and Attendance Dataset by Marvy Ayman Halim, via Kaggle. Five CSV files: students, attendance, homework, performance (exam scores), and teacher-parent communication logs.

Methods: pandas for cleaning/merging/aggregation, matplotlib and Plotly for visualization. See DATA_CLEANING_BRIEF.md in ../data/ for a full writeup of cleaning decisions.

  • students.csv has no gender field — grade-level is used as the class/grouping variable instead

4. Cleaning¶

In [4]:
def parse_date(series):
    return pd.to_datetime(series, errors="coerce", format="mixed")

def clean_percent(series):
    s = series.astype(str).str.strip().str.replace("%", "", regex=False)
    return pd.to_numeric(s, errors="coerce")

# --- students ---
students = students_raw.copy()
students["Date_of_Birth"] = parse_date(students["Date_of_Birth"])
students["Grade_Level"] = students["Grade_Level"].astype(str).str.strip()

# --- attendance ---
attendance = attendance_raw.copy()
attendance["Date"] = parse_date(attendance["Date"])
status = attendance["Attendance_Status"].astype(str).str.strip().str.lower()
status_map = {"present": "Present", "absent": "Absent", "excused": "Excused", "late": "Late"}
attendance["Attendance_Status"] = status.map(status_map).fillna(status.str.title())
attendance["Subject"] = attendance["Subject"].astype(str).str.strip()

# --- homework ---
homework = homework_raw.copy()
homework["Due_Date"] = parse_date(homework["Due_Date"])
status = homework["Status"].astype(str).str.strip()
homework["Status"] = status.map({"❌": "Not Done", "✅": "Done", "Done": "Done", "done": "Done"}).fillna(status)
homework["Subject"] = homework["Subject"].astype(str).str.strip()

# --- performance ---
performance = performance_raw.copy()
performance["Exam_Score"] = pd.to_numeric(performance["Exam_Score"], errors="coerce")
performance["Homework_Completion_%"] = clean_percent(performance["Homework_Completion_%"])
performance["Subject"] = performance["Subject"].astype(str).str.strip()

# --- communication ---
communication = communication_raw.copy()
communication["Date"] = parse_date(communication["Date"])

print("Cleaned attendance status values:", attendance["Attendance_Status"].unique())
print("Cleaned homework status values:", homework["Status"].unique())

5. Merge into a Master Analysis Table¶

One row per (student, subject), combining exam performance with attendance rate and homework completion for that student.

In [5]:
attendance["is_present"] = attendance["Attendance_Status"] == "Present"
att_overall = (attendance.groupby("Student_ID")["is_present"].mean().mul(100).round(1)
               .rename("Overall_Attendance_Rate_%").reset_index())
att_subject = (attendance.groupby(["Student_ID", "Subject"])["is_present"].mean().mul(100).round(1)
               .rename("Attendance_Rate_%").reset_index())

homework["is_done"] = homework["Status"] == "Done"
hw_overall = (homework.groupby("Student_ID")["is_done"].mean().mul(100).round(1)
              .rename("Homework_Done_Rate_%").reset_index())

perf_agg = (performance.groupby(["Student_ID", "Subject"])
            .agg(Exam_Score=("Exam_Score", "mean"),
                 Homework_Completion_pct=("Homework_Completion_%", "mean"))
            .reset_index())

master = perf_agg.merge(students[["Student_ID", "Full_Name", "Grade_Level"]], on="Student_ID", how="left")
master = master.merge(att_subject, on=["Student_ID", "Subject"], how="left")
master = master.merge(att_overall, on="Student_ID", how="left")
master = master.merge(hw_overall, on="Student_ID", how="left")

8. Key Insights¶

  • Average exam scores are consistent across subjects (mid-70s), with no subject standing out as substantially harder or easier.
  • Correlations between attendance rate and exam score, and between homework completion and exam score, are close to zero across every subject. This dataset does not show the attendance/homework → performance relationship one might expect from real classroom data — consistent with the dataset being synthetically generated rather than collected from real outcomes.
  • Attendance rates by grade and subject (heatmap) show no systematic pattern favoring any particular grade or subject.
  • The monthly attendance trend is roughly flat over the covered period, without strong seasonal dips (e.g., no clear holiday effect).

Suggested next steps: with real (non-synthetic) data, a natural extension would be a predictive model — e.g., regression to estimate exam score from attendance/homework features, or classification to flag at-risk students — which was out of scope for this submission.
